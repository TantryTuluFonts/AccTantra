# Conjunct reference

A conjunct (two consonants joined into one shape) is typed as **first consonant + `A` + second consonant**, where `A` is the virama key. For example `kAt` joins *k* and *t*.

The fonts build the joined shape in two ways, and this page is generated from each font's own ligature table (`liga`), so it lists what actually exists:

- **Dedicated conjunct glyphs** (`C A C`): one glyph for the whole pair, e.g. `kAt`.
- **Second-consonant forms** (`A C`): a glyph for the virama followed by a consonant, used after any first consonant.

| Font | Dedicated `C A C` glyphs | Second-consonant (`A C`) forms | All ligature sequences |
|---|---|---|---|
| Darage | 72 | 33 | 298 |
| Mandara | 1 | 34 | 99 |
| Allige | 0 | 34 | 66 |
| Mallige | 177 | 34 | 1524 |

In each list a line reads "first consonant + `A` + [second consonants]".

## Mandara

Second-consonant forms (`A` + any of): `kKgGzcCjJZqQwWNtTdDnpPbBmyrlLvSxsh`

Dedicated conjunct glyphs:

```text

```
